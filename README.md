# The Greenhouse Effect Master

**Read. Understand. Analyse. Remember.**

Interactive bilingual Progressive Web App for **West Bengal (India)** Bengali-medium Class XII students studying Carl Dennis’s **The Greenhouse Effect**.

## Features

- Full poem with line-by-line analysis and clickable vocabulary
- English / বাংলা / BOTH modes · Simple mode · Teach Me
- Themes: climate, poverty, civilisation, adaptation, power shift
- Literary devices, critical appreciation, exam bank, 25+ MCQs
- Flashcards, revision, progress · Offline PWA
- **India 🇮🇳 only** (no Bangladesh flags)

## Run

Open `index.html` or use GitHub Pages after enabling it in repo Settings.

```bash
npx serve .
```

## Content source

Class XII textbook pages 180–182, with scaffolding for Bengali-medium learners in West Bengal, India.
